# 周大航任务系统

一个面向小朋友的本地任务打卡与奖赏系统：家长在电脑上运行本地服务，小朋友在电脑或手机浏览器里完成任务、打卡攒分，攒够分数兑换心愿奖赏。

界面是漫画糖果风（全部图标为内联 SVG，不依赖网络图片），数据保存在项目目录的 `data.json`，跟随文件夹迁移，换电脑也能续上。

## 功能特性

- 多小朋友：一个系统可管理多个孩子，左上角切换后顶部标题、任务、奖赏、分数都会跟着切换
- 任务管理：单次 / 重复模式，支持每小时、每天、每周、每月四种间隔；可设置开始/结束时间、图标、完成加分、未完成扣分
- 打卡流程：支持手动确认和倒计时两种验收方式；打卡前有时间校验、家长锁校验
- 奖赏进度：按累计分数展示奖赏完成百分比，差多少分实时提示
- 日历与统计：按日期查看历史打卡状态、当日完成率和连续打卡
- 操作记录：今日加分/扣分/打卡记录默认折叠，可展开并撤销
- 家长锁：密码只保存加盐哈希；上锁后不能增删改数据，打卡不受影响
- 开机语音：进入系统约 2 秒后自动播放语音（素材在 `assets/voice/niulai.mp3`）
- 数据安全：每次写入自动备份到 `backups/`，提供备份/恢复工具
- 移动端优化：手机窄屏自动关闭毛玻璃、固定背景等高开销效果；静态资源强缓存

## 技术栈

- 前端：原生 HTML / CSS / JavaScript，无框架、无构建步骤
- 后端：Python 标准库 `http.server`（`ThreadingHTTPServer`），无需 `pip install`
- 存储：浏览器 `localStorage` + 服务端 `data.json` 双向同步

## 快速开始

### 环境要求

- Windows（启动脚本为 `.bat`）
- Python 3.8 及以上，且已加入 PATH

### 启动

双击「启动服务器.bat」，或在本目录执行：

```bash
python server.py        # 默认端口 8080
python server.py 8090   # 也可指定其它端口
```

启动后会打印本机地址与局域网地址：

- 电脑访问：`http://localhost:8080`
- 手机 / 平板：`http://<局域网IP>:8080`（需与电脑处于同一 WiFi）

首次启动脚本会尝试自动放行 Windows 防火墙；点击左上角的螃蟹 / 龙虾图标可创建桌面快捷方式。

### 停止

双击「停止服务器.bat」，或在运行窗口按 `Ctrl + C`。

## 任务与打卡规则

### 任务类型

- 单次（`single`）：只在指定日期（`scheduledDate`）当天出现，打卡后当天保持已完成，次日起不再出现在任务列表
- 重复（`repeat`）：按间隔周期重置
  - 每小时：每小时可重新打卡
  - 每天：每天重置，次日恢复为可打卡
  - 每周：可指定星期几，未指定则每天可打，按自然周重置
  - 每月：按自然月重置

### 时间与校验

- 任务开始时间仅作为提醒与打卡门槛：早于开始时间点击打卡会二次确认，选择「确定」仍可打卡，选择「取消」则中止
- 单次任务的打卡状态统一按「天」计算，当天有效、次日清零
- 验收方式为倒计时时，需等待倒计时结束再确认是否完成
- 选择「未完成」会按任务设置的扣分扣分，并记录一条未完成记录；未设置扣分则记 0 分
- 撤销记录会同步回退小朋友总分，并让任务状态回到可打卡

### 积分

- 小朋友总分为每条打卡记录分值之和（含手动加减分），允许为负
- 删除任务会连同其打卡记录一起清理，并回退对应积分

## 数据与备份

### 数据文件

`data.json` 主要字段：

| 字段 | 说明 |
| --- | --- |
| `children` | 小朋友列表（昵称、头像、累计分数） |
| `tasks` | 任务列表（类型、间隔、时间、分值、图标等） |
| `rewards` | 奖赏列表（名称、图标/图片、目标分数） |
| `scoreLogs` | 打卡与加减分记录（周期 key、是否完成、分值、时间戳） |
| `currentChildId` | 当前选中的小朋友 |
| `parent` | 家长密码（盐 + 哈希，不存明文） |
| `lockState` | 家长锁状态（所有设备共用） |
| `updatedAt` | 数据版本时间戳，用于多设备同步判断 |

同步规则：页面读写走 `localStorage`，保存后防抖 300ms 推送整份快照到服务端；启动时按 `updatedAt` 决定使用服务端数据还是把本地数据推上去，避免旧数据覆盖新数据。

### 自动备份

- 每次写入 `data.json` 后按需留档到 `backups/`，最快 5 分钟一份，内容没变化则跳过
- 保留策略：最近 120 份全留；另外每天最后一份保留 90 天
- 手动备份 / 恢复：

```bash
python backup_tool.py --list            # 列出备份
python backup_tool.py --backup          # 立即备份
python backup_tool.py --restore 1       # 恢复列表中第 1 份（最新）
python backup_tool.py --restore data-20261027-153000.json
```

也可以双击「备份与恢复.bat」使用交互菜单。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/data` | 读取整份数据快照 |
| POST | `/api/data` | 整份数据写入 `data.json` 并触发自动备份 |
| GET | `/api/info` | 返回本机局域网 IP 与端口 |
| POST | `/api/shortcut` | 在桌面创建「周大航任务系统」快捷方式 |

`backups/` 目录不对外提供下载，访问会被拒绝。

## 维护与二次开发

- 改完 `js/*.js`、`css/style.css` 后，需要递增 `index.html` 中对应的 `?v=` 版本号：
  - 带版本号的 js/css 已被服务端设置为一年强缓存，版本号不变手机端会继续用旧文件
  - 页面和接口仍为 `no-store`，数据实时
- 新增任务图标：在 `js/icons.js` 的 `ICONS` 中加 SVG，并在 `TASK_ICON_OPTIONS` 增加选项；`guessTaskIcon` 可按任务名自动匹配
- 替换开机语音：覆盖 `assets/voice/niulai.mp3` 即可（浏览器限制自动播放，页面会在加载后 2 秒尝试播放）
- 移动端性能：`css/style.css` 末尾的 `@media (max-width: 768px)` 会关闭毛玻璃、固定背景和常驻动画，桌面端样式不受影响

## 常见问题

**手机打不开页面？**
确认手机与电脑在同一 WiFi，使用启动时打印的局域网地址；若仍不行，检查 Windows 防火墙是否放行 8080 端口。

**手机端第一次打开偏慢或卡顿？**
首次需要下载页面与脚本；之后静态资源走强缓存会明显变快。如果刚更新过版本，请用 `Ctrl + F5` 或在手机浏览器里强制刷新一次。滚动卡顿已在窄屏下关闭毛玻璃与固定背景。

**iOS 进入后没有声音？**
浏览器禁止无交互自动播放，页面会在被拦截时显示「点我播放」按钮。iOS 15.4+ / Safari 16.4+ 下页面已把音频会话切为 `playback`，侧边静音开关打开也能出声；更老系统只能手动关闭静音开关。

**分数或记录对不上？**
先确认没有多台设备同时编辑同一份数据（以 `updatedAt` 较新者为准），必要时用 `backup_tool.py` 恢复最近备份。

**根目录出现 `.data-*.tmp` 文件？**
这是写入 `data.json` 时的临时文件，正常会被自动替换掉；若因中断残留，确认 `data.json` 正常后可直接删除。
